四、主要功能
--------------------------------------------------------------------------------
  1. 知识摄入：支持 Markdown、纯文本、PDF、DOCX、CSV（FAQ）等多种文档格式
     的批量上传与索引；对文档自动分块（400 字符窗口、40 字符重叠）；重复
     文档上传幂等处理，不产生重复索引。
  2. 中文友好检索：基于 SQLite FTS5 + unicode61 分词器，对中文（汉）序列
     采用二元切词（bigram）建立索引与构造查询，结合 BM25 相关度排序，能够
     在纯离线环境下准确命中中文知识片段。
  3. 离线问答：对用户提问进行检索，返回「答案建议 + 置信度 + 引用来源（文档
     名 + 段落号 + 原文摘录）」，默认路径不依赖任何外部大模型与向量模型。
  4. 领域预设：内置法律（律师事务所）、医疗（诊所）、招采（中标公告）、通用
     四个领域模板包，可配置问候语、引导语、兜底语及可选系统提示词。
  5. 管理后台：提供文档管理（列表、分块预览、删除）、批量上传、查询日志与
     统计（总查询量、命中率）等功能。
  6. 嵌入式浮窗：提供 widget.js 脚本，第三方站点引用即可嵌入网页聊天浮窗，
     支持跨域配置（RAGDESK_ALLOW_ORIGIN）与可选令牌鉴权。
  7. 安全与部署：管理端可选令牌（x-admin-token）鉴权；提供 Docker Compose
     一键部署与健康检查接口。

五、技术创新点
--------------------------------------------------------------------------------
  1. 完全离线检索问答：默认运行路径不依赖任何外部 LLM 或 embedding 模型，
     仅使用本地 SQLite FTS5 + BM25 完成知识检索与回答生成，数据完全驻留本
     机，适合对数据安全与保密性要求高的政企场景。
  2. 中文二元切词方案：针对 FTS5 对中文切词能力弱的短板，设计了 CJK
     bigram 索引扩展与查询扩词算法（tokenizer.js），中文短查询命中率显著
     提升，且全部在本地实现，零外部服务依赖。
  3. 段落感知分块：按空行划分段落、超长段落重叠切窗、短段落合并打包，保证
     检索单元的上下文完整性与一致性，从而提升回答引用的准确性。
  4. 可溯源引用回答：每条回答均附带文档名、段落号与原文摘录，具备可核查性，
     适用于法律、医疗、招采等对来源有严格要求的行业。
  5. 轻量可嵌入：单服务、无构建步骤，前端原生实现，通过一段 script 标签即可
     将问答能力嵌入任意网站。
